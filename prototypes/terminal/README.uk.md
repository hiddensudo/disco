# Прототип термінала disco

[English](README.md)

Окремий нативний експеримент на egui 0.37. Не змінює встановлений disco, його налаштування, кеш сканування чи номер релізу. Версія пакета відповідає основному проєкту; це не реліз.

```sh
./run.sh --folder /шлях/до/проєкту
```

Скрипт запускає локальну збірку прототипу, якщо вона є; інакше збирає через Cargo. Ручна збірка: `cargo build --manifest-path Cargo.toml --locked`.

- **Праворуч** і **Знизу** — незалежні справжні PTY-сесії. Нижня оболонка запускається тільки після відкриття панелі. Приховування зберігає сесію; **Нова** завершує її та запускає заміну.
- Використовується `$SHELL`, потім оболонка облікового запису, потім `/bin/sh`. Можна вказати `--shell /bin/bash`.
- Нова сесія стартує в папці, показаній зверху. Перехід між папками не змінює робочу директорію вже відкритих сесій.
- Межі панелей перетягуються; A−/A+ змінюють розмір тексту термінала.
- Клік у термінал переводить туди фокус; після відведення миші клавіатура продовжує працювати. Ctrl+C перериває процес, Ctrl+Shift+C/V копіюють/вставляють, Ctrl+` перемикає нижню панель. У заголовку також є кнопки копіювання/вставлення.
- `--en` вмикає англійську; типово — українська.
- Дерево файлів і текстовий перегляд — невелике тестове оточення лише для читання, а не весь робочий простір disco.

## Швидкість і межі прототипу

Вікно прокидається від PTY-подій та вводу користувача. Постійного циклу перемальовування немає. UI p95 — час побудови інтерфейсу на CPU, а не час GPU, частота монітора чи повна затримка вводу. PTY — час від запуску оболонки до першого видимого непорожнього виводу, включно з її конфігом.

Тести зі справжніми PTY перевіряють клавіатуру поза положенням миші, Unicode, вставлення, альтернативний екран, незалежність сесій, resize, Ctrl+C, завершення процесів і 5 000 рядків історії:

```sh
cargo test --workspace --locked -- --nocapture
```

Сумісність із конкретними інтерактивними програмами потрібно ще перевірити вручну. Повної сумісності всіх термінальних можливостей прототип не обіцяє. Перенесення однієї сесії між позиціями поки немає: праворуч і знизу окремі сесії. Закриття вікна або «Нова» завершує процеси відповідної сесії. OSC 52 для буфера обміну та збереження живих сесій між перезапусками апки не входять у цей експеримент.

## Основа

eframe/egui для UI, Alacritty для стану термінала й PTY, адаптований MIT-віджет [egui_term](https://github.com/kemokempo/egui_term). Версія джерел і зміни записані в [../../vendor/egui_term/UPSTREAM.md](../../vendor/egui_term/UPSTREAM.md). Вбудованого браузера чи JavaScript немає.

[Результати замірів](MEASUREMENTS.md).

Кольори й шрифти: успадковане NO_COLOR прибирається до запуску потоків; системний моноширинний шрифт та додаткові символи підтягуються через Fontconfig (fc-match), зі стандартними fallback-шрифтами. Це стосується лише процесу прототипу та його дочірніх процесів.
